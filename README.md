# Website Lim Alda — Content Creator

Website portofolio pribadi dengan desain hitam-merah dan tiga menu: Identitas Diri, Hobi, dan Sosial Media.

## Cara mencoba
Ekstrak ZIP lalu buka `index.html` di browser.

## Personalisasi
- Ganti `assets/foto-profil-placeholder.svg` dengan foto pribadi. Jika memakai nama file berbeda, ubah atribut `src` pada `index.html`.
- Ganti tautan Facebook, Instagram, dan TikTok di bagian `#sosial` dengan URL akun asli.
- Ubah deskripsi profil sesuai kebutuhan.

## Publikasi GitHub Pages
Unggah `index.html`, `style.css`, `script.js`, dan folder `assets` ke repository GitHub. Buka Settings → Pages, pilih Deploy from a branch, branch `main`, folder `/ (root)`, lalu simpan.

## Google Sites
Google Sites tidak mengimpor ZIP/HTML sebagai desain native. Buat halaman serupa secara visual di Google Sites, atau sematkan URL GitHub Pages lewat Sisipkan → Sematkan → URL. GitHub Pages dan Google Sites adalah opsi publikasi yang berbeda.
